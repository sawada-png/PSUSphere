# PSUSphere

## Project Name

**PSUSphere**

## Short Description

PSUSphere is a Django-based web application designed to manage student organizations, colleges, academic programs, and student memberships in one system.

## Features

* Manage colleges and their information
* Manage academic programs and their associated colleges
* Manage student organizations
* Manage student information
* Manage student organization memberships
* Search and filter records through the Django Admin
* Automatically track record creation and update dates
* Generate initial sample data for testing
